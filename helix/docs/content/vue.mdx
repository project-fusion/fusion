# Vue

```ts
import '@fusion.dev/helix/vue'
```

Add this types-only import once. It augments Vue's `GlobalComponents`, so every
Helix tag in an SFC template has typed props and events. The generated file
declares the augmentation under both `vue` and `@vue/runtime-core`, because
different tools read different ones.

## Mark Helix tags as custom elements

Without this setting, Vue treats `<helix-button>` as a component it cannot find
and logs a warning on every render.

```ts
// vite.config.ts
export default defineConfig({
  plugins: [
    vue({
      template: { compilerOptions: { isCustomElement: (tag) => tag.startsWith('helix-') } },
    }),
  ],
})
```

The prefix test is enough. Every Helix element name starts with `helix-`, in
both tiers, and no other name in the library does.

## Pass props and bind events

Vue sets a property when the element has one, and sets an attribute otherwise.
That works for every Helix element. A string goes through either path, and an
array or an object goes through the property.

```vue
<helix-data-table label="People" :rows="people" />
<helix-tabs @helix-before-activate="onActivate" />
```

`@helix-before-activate` binds with `addEventListener`, so use the event's own
name. Vue needs no bridge and no wrapper. The compiler setting above is the only
setup.

To force a property, use `.prop`. You may need it where a string would be
ambiguous:

```vue
<helix-input :value.prop="'42'" />
```

You will rarely need `.prop`.

## Seed, mirror, or refuse a value

`value`, `open`, `checked`, and `active` are seeds. The element starts with the
value you set and then applies its own changes, so all three of these patterns
work. See [State and control](./state-and-control).

```vue
<!-- Seeded: the element owns it from there. -->
<helix-input default-value="Ada" label="Name" />

<!-- Mirrored: bind the notification and let the element apply. -->
<helix-input label="Name" @change="name = $event.target.value" />

<!-- Refused: you take the decision for this one change. -->
<helix-input
  :value="name"
  label="Name"
  @helix-before-change="$event.preventDefault(); name = clean($event.detail.value)"
/>
```
