# Theme builder

[Open the theme builder](/helix/theme).

When you move a slider, every component in the preview updates. Helix computes
a theme from a few inputs, and the theme builder shows you the result.

## What the theme builder shows

You enter the same inputs that `derive()` takes:

- a brand color
- a chroma ceiling
- a radius
- a density
- a contrast target
- a motion character

The theme builder runs the full derivation. It shows you every token, and the
components drawn with them.

It shows light and dark at the same time. `[data-color-mode]` works on any
element, so the two previews are two subtrees of one document. See
[Color modes](./color-modes).

## The contrast column

The contrast column lists every color pair Helix computed. Each pair shows its
ratio, measured against the background it is painted on. A pair has one of
three states:

- **Met.** The pair reaches the target.
- **Unverifiable.** The background is translucent, so there is no known color
  to measure against. The pair neither passes nor fails. This is the cost of a
  translucent material, and the theme builder reports it.
- **Pinned.** You set the color yourself. The engine did not compute it, so its
  contrast is not guaranteed.

A column of `unverifiable` pairs means your theme makes a trade. The column lets
you see that you made it.

## What the theme builder exports

The theme builder gives you the token block as CSS, to paste into your own
stylesheet:

```css
:root {
  --helix-color-primary: oklch(…);
  …
}
```

It also gives you the intent object, to keep in your repository and derive the
theme from again:

```ts
export const theme = { brand: '#2563eb', chroma: { ceiling: 0.1 }, radius: 2 }
```

**Keep the intent object in your repository.** The tokens are the output of a
solver, and the solver improves. A theme stored as its inputs gets each
improvement. A theme stored as token values stays at the version that produced
it. Use the tokens only in a system that cannot run the engine.

## Limits of the theme builder

The theme builder shows numbers and swatches. It does not show components in
your product. The contrast results are a grid with three states, and a terminal
or a table shows that grid more clearly than a picture. The components beside
it are for checking the result. They are not a design tool.
