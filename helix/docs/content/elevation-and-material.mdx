# Elevation and material

## Layers

[//]: # (tokens:layer)

| Token | Value |
| --- | --- |
| `--helix-layer-beneath` | `-1` |
| `--helix-layer-base` | `0` |
| `--helix-layer-raised` | `10` |
| `--helix-layer-sticky` | `100` |
| `--helix-layer-overlay` | `1000` |
| `--helix-layer-toast` | `1200` |

[//]: # (/tokens)

The five main layers are named after what sits at each one. A numbered scale
leads to values such as `z-index: 1001` that nobody can explain, and those
values cause stacking context bugs.

| Layer | What is at it |
|---|---|
| `base` | The document |
| `raised` | Something lifted but still in the flow: a hovered row, a dragged card |
| `sticky` | A header or a column that stays while content scrolls under it |
| `overlay` | Menus, dialogs, popovers, tooltips |
| `toast` | Above everything, including a modal |

**Most overlays do not need these tokens.** They use the popover API and render
in the browser's top layer, which is always above every z-index. Use the tokens
for the cases the top layer does not cover:

- your own sticky header
- your own dragged element
- anything that has to sit between two of our layers

## Shadows

| Token | Value |
| --- | --- |
| `--helix-shadow-none` | `none` |
| `--helix-shadow-sm` | `0 1px 2px light-dark(color-mix(in oklab, oklch(0.15 var(--helix-seed-neutral-chroma, 0) var(--helix-seed-neutral-hue, 258)) 5%, transparent), color-mix(in oklab, oklch(0.15 var(--helix-seed-neutral-chroma, 0) var(--helix-seed-neutral-hue, 258)) 8%, transparent))` |
| `--helix-shadow-md` | `0 4px 12px light-dark(color-mix(in oklab, oklch(0.15 var(--helix-seed-neutral-chroma, 0) var(--helix-seed-neutral-hue, 258)) 6%, transparent), color-mix(in oklab, oklch(0.15 var(--helix-seed-neutral-chroma, 0) var(--helix-seed-neutral-hue, 258)) 10%, transparent))` |
| `--helix-shadow-lg` | `0 12px 32px light-dark(color-mix(in oklab, oklch(0.15 var(--helix-seed-neutral-chroma, 0) var(--helix-seed-neutral-hue, 258)) 9%, transparent), color-mix(in oklab, oklch(0.15 var(--helix-seed-neutral-chroma, 0) var(--helix-seed-neutral-hue, 258)) 14%, transparent))` |
| `--helix-shadow-surface` | `var(--helix-shadow-none)` |
| `--helix-shadow-floating` | `var(--helix-shadow-lg)` |
| `--helix-shadow-raised` | `var(--helix-shadow-floating)` |

[//]: # (/tokens)

The first four are the values. The last three are policy tokens. A theme sets
them to make your interface shadow-first or border-first. See [Surfaces and
separation](./surfaces-and-separation).

## Material

These tokens describe translucency:

[//]: # (tokens:material)

| Token | Value | For |
| --- | --- | --- |
| `--helix-material-backdrop` | `blur(var(--helix-material-blur-md)) saturate(1.5)` | The blur and saturation behind a translucent surface. |
| `--helix-material-opacity` | `1` | How opaque a translucent surface is. |
| `--helix-material-glass-opacity` | `calc(0.72 * var(--helix-material-opacity))` | How much of a mark a glass material covers. |
| `--helix-material-frosted-opacity` | `calc(0.88 * var(--helix-material-opacity))` | How much of a mark a frosted material covers. |
| `--helix-material-blur-sm` | `8px` | The lightest backdrop blur. |
| `--helix-material-blur-md` | `16px` | The backdrop blur behind a modal. |
| `--helix-material-blur-lg` | `32px` | The heaviest backdrop blur. |
| `--helix-material-translucent` | `light-dark(color-mix(in oklab, oklch(1 0 0) min(100%, 30% * var(--helix-material-opacity)), transparent), color-mix(in oklab, oklch(0.182 var(--helix-seed-neutral-chroma, 0) var(--helix-seed-neutral-hue, 258)) min(100%, 60% * var(--helix-material-opacity)), transparent))` | The translucent background, for a surface that shows what is behind it. |
| `--helix-material-translucent-strong` | `color-mix(in oklab, light-dark(oklch(1 0 0), oklch(0.182 var(--helix-seed-neutral-chroma, 0) var(--helix-seed-neutral-hue, 258))) min(100%, 88% * var(--helix-material-opacity)), transparent)` | The stronger translucent background, for a surface that shows less of what is behind it. |
| `--helix-material-panel` | `light-dark(color-mix(in oklab, oklch(1 0 0) min(100%, 72% * var(--helix-material-opacity)), transparent), var(--helix-material-translucent))` | The glass of every panel, from a Menu, Popover, or Tooltip to a Dialog or Drawer over its scrim. |
| `--helix-material-border` | `light-dark(color-mix(in oklab, oklch(0.15 var(--helix-seed-neutral-chroma, 0) var(--helix-seed-neutral-hue, 258)) 14%, transparent), color-mix(in oklab, oklch(1 0 0) 12%, transparent))` | The border a translucent surface needs to keep a visible edge. |

[//]: # (/tokens)

The `material` axis draws its three values, `frosted`, `glass`, and
`transparent`, with these tokens. Material is an axis of its own, separate from
`emphasis`, because a panel can be glass and outlined at the same time. Two
properties that can apply at once belong on two axes. See [Visual
axes](./visual-axes).

**Use blur with care, because it is expensive.** A `backdrop-filter` makes the
compositor read what is behind the element again on every frame the element
moves. A frosted header that is always on screen pays that cost all the time.
When you want depth without the frosted texture, use `translucent` without the
blur.

A translucent surface takes its color from what is behind it, so on a busy
background it has no visible edge. `material-border` gives it one, so it keeps
its shape.
