# Svelte

```ts
import '@fusion.dev/helix/svelte'
```

Add this types-only import once. It augments `SvelteHTMLElements`, so every
Helix tag is typed in a component. The import re-exports the JSX types. Svelte
binds a handler as `onhelix-before-change={…}`, which is the shape those types
already describe. With one shared copy of the types, the Svelte and JSX typings
cannot disagree.

## Pass props and bind events

```svelte
<helix-input label="Name" onchange={(event) => (name = event.target.value)} value={name} />
```

Svelte sets a property when the element has one, and an attribute otherwise. It
binds `on*` with `addEventListener`. Svelte shows no unknown-element warning,
and you do not need a compiler flag.

Svelte passes objects and arrays as properties on its own:

```svelte
<helix-tabs items={tabs} />
```

## Read values and refuse changes

These two rules apply in every framework.

`bind:` does not work on a Helix control, because custom elements have no
two-way binding convention to opt into. Read the value from the event.

A declared `value`, `open`, `checked`, or `active` is a seed. The element starts
with that value and then applies its own changes. To refuse a change, cancel the
matching `helix-before-*` event. Skipping a state update does not refuse it. See
[State and control](./state-and-control).
