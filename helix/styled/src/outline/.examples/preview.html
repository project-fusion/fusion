Install Install the package with your package manager, then import it once in the entry file of your app before you use it. Requirements The package needs a current version of Node.js and a browser that supports custom elements and modern JavaScript. Usage Create a client with your API key, then call its methods to read and write the projects, files, and users in your account. Options Pass options when you create the client to set the request timeout, the number of retries, and the base URL to use. API Each method returns a promise. Errors include a code and a message that you can show to the people who use your app.
