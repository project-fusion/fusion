Assistant How do I roll back the migration that failed this morning?

Roll back 0042_add_order_status

It stopped halfway, so orders has the new column and no index yet. Rolling back is safe: nothing has written to the column.

  1. Pause the workers that write to orders.
  2. Run the down migration.
  3. Check the column is gone, then start the workers again.
bun run migrate:down 0042_add_order_status
Option Downtime Keeps data

Restore the snapshot Twenty minutes No
