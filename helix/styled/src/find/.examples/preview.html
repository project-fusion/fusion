Theming with tokens

A token names one decision, such as the color of a border or the space between two controls. Components read tokens, so a theme changes every component at once.

Set a token on the page to change it everywhere, or on one element to change it there. A token set on an element reaches everything inside it.

Choosing colors

Start from the primary color. The other color tokens are mixed from it and from the page's foreground and background.
