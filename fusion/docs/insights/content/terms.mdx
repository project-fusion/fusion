## The sandbox runs your code in your browser

`/helix/sandbox` and `/helix/theme` run the code you type into them.

Your code runs inside an iframe with `sandbox="allow-scripts allow-forms"`. The
iframe does not have `allow-same-origin`, so the document runs with an opaque
origin. It cannot read our cookies or storage, call our origin, or reach any of
our systems. It is your code, running in your browser.

This has two consequences:

- We do not receive what you type. The source you edit is never sent to a
  server, so we cannot keep it, and we do not.
- We are not responsible for what your code does in your own browser.

Do not paste a secret into the sandbox, for the same reason you would not paste
one into a browser console: you have no way to confirm that we do not read it.
