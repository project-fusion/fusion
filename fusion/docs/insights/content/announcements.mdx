Fusion has five layers, and today only the top one, the interface layer, is
ready to use. We are finishing that layer first. We ship it as a design system,
because a design system is the part of an interface a company can own.

## What Helix is

Every component is a custom element. React, Vue, and Svelte all use the same
element.

Helix comes in two tiers:

- The headless tier has the behavior and no styles: state, focus, keyboard,
  forms, and accessibility.
- The styled tier adds a visual design to the same components.

If you need a different look, you use the headless tier and keep the same
components. You do not have to copy a file and maintain a fork.

## What you get

You give Helix one brand color, and it computes the whole palette. Helix rejects
a palette it cannot make readable, so contrast is part of how the colors are
made.

Every tag, property, and event is in one manifest at a URL, and every page is
available as Markdown. AI agents read the same pages you do, so there is one
copy of the API for both.

Helix is MIT licensed. It lives in your repository and keeps working after we
leave. We hold every Fusion product to that test.

## What is next

Cortex is the layer under Helix. It stores what your company knows and where
each fact came from, and you own that record. Work on Cortex is underway, and
nothing has shipped yet. We will announce it here when it does.

We are not setting dates for any of it.
