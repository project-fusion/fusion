# Cortex

Cortex is a memory and provenance layer for AI systems. It is written in Rust,
keeps data on your machine by default, and works with any storage backend.

It adds two things to a model call:

- **Memory** that persists, consolidates, and forgets. A log of every event is
  the raw material that memory is built from.
- **Provenance** that traces every output to its inputs, so you can answer "why
  did it say that?" for any answer. Every other part of Cortex is built on it.

## Why local-first

If a system that remembers you stores that memory on someone else's server, you
still depend on that server.

Cortex will store everything in a single SQLite file on your machine by
default. Today the stores in the crates keep data in memory. SQLite and
Postgres are planned behind a shared trait, and a hosted tier will be an
option. The `Provider` trait has an `is_local` flag, so a product can tell you
whether your data left the device:

[//]: # (rust:fusion-cortex-core::provider::MockProvider)

```rust
use fusion_cortex_core::provider::{MockProvider, Provider};

let provider = MockProvider { reply: "hello".into() };
assert!(provider.is_local());
```

## Primitives

| Module | Crate | Owns |
| --- | --- | --- |
| **Engram** | `fusion-cortex-engram` | Memory: episodic, semantic, later procedural |
| **Trace** | `fusion-cortex-trace` | Provenance: `why()`, replay, cascading deletion |
| **Recall** | `fusion-cortex-recall` | Context assembly. Not yet built |
| Core | `fusion-cortex-core` | Identifiers, provider abstraction, shared errors |

Engram, Trace, and Recall have names of their own because each is a distinct
idea. Everything else has a descriptive name.

## Identifiers

Ids are UUIDv7. The timestamp at the start of each id makes ids sort in the
order they were created. An index stays in order, and a time-range scan over
episodic memory needs no separate time column.

[//]: # (rust:fusion-cortex-core::Id)

```rust
use fusion_cortex_core::Id;

let first = Id::new();
let second = Id::new();
assert!(first <= second);
```
