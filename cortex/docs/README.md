# @fusion.dev/cortex-docs

The Cortex documentation as content: the pages, and the registry that names them.

```sh
npm install @fusion.dev/cortex-docs
```

```js
import { findPage, pages, sections } from '@fusion.dev/cortex-docs'
```

Cortex is a memory and provenance substrate. This package carries its
documentation at the version of Cortex it describes, the same arrangement
[`@fusion.dev/helix-docs`](https://www.npmjs.com/package/@fusion.dev/helix-docs)
uses, which is why versioning is per domain rather than per repository.
