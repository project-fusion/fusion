# @fusion.dev/cortex-cli-linux-arm64

The `cortex` binary for Linux on 64-bit Arm, statically linked. Install
[`@fusion.dev/cortex-cli`](https://www.npmjs.com/package/@fusion.dev/cortex-cli)
instead: npm installs this beside it on a matching machine, and the `cortex`
command it provides runs this.
